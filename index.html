ตั้งค่าครั้งแรก · สำหรับผู้ดูแล

เชื่อมห้องพักครูกับฐานข้อมูลออนไลน์

หน้านี้เปิดจากนอก Google Apps Script (เช่น GitHub Pages) จึงต้องรู้ที่อยู่ Web app ของคุณก่อน ระบบล็อกอิน แชต realtime และกระดานจึงจะทำงาน

  1. ใน Apps Script กด Deploy → New deployment → Web app
  2. ตั้ง Execute as: Me และ Who has access: Anyone
  3. คัดลอก Web app URL (ลงท้ายด้วย /exec) มาวางด้านล่าง
ห้องพักครูออนไลน์

เข้าห้องพักครู แล้วเจอเพื่อนครูแบบ realtime

สมาชิกจะได้สมุดส่วนตัวที่เก็บในบัญชี (จดหมาย ไพ่ โพสต์ที่บันทึกไว้) เปิดจากเครื่องไหนก็เจอ ส่วนผู้เยี่ยมชมเข้าร่วมแชตและวง PLC ได้ทันทีโดยไม่ต้องสมัคร

แต่งตัวกันก่อน แล้วค่อยเข้าห้องพักครูนะ

ห้องพักครูนี้เป็นที่พักใจของครูทุกคน มีเพื่อนครู มุมกาแฟ โซฟารับฟัง และอีกหลายมุมให้แวะพัก ก่อนเปิดประตูเข้าไป มาสร้างตัวละครที่เป็นตัวคุณกันก่อน

  • 1ตั้งชื่อ เลือกเพศและสีผิว
  • 2เลือกทรงผมและสีผม ดูจากรูปตัวอย่างได้เลย
  • 3เลือกชุดครู มีทั้งชุดที่ครูใส่ประจำ (ชุดไทย ชุดกากี ชุดปกติขาว ชุดพละ) ชุดประจำวิชา และชุดลำลอง รวม 23 แบบ
  • 4ใส่เครื่องประดับ แล้วส่องกระจกหน้าประตูเพื่อบอกว่าวันนี้รู้สึกอย่างไร

วิธีเล่น

  • คลิก / แตะแตะพื้นเพื่อเดิน แตะสิ่งของหรือเพื่อนครู ตัวละครจะเดินไปทำกิจกรรมเอง
  • W A S Dเดินด้วยคีย์บอร์ด (ใช้ลูกศรได้)
  • E / Spaceคุยหรือใช้ของที่อยู่ใกล้ที่สุด
  • ลากหน้าจอหมุนมุมกล้อง ใช้ปุ่ม + − หรือล้อเมาส์เพื่อซูม
  • มุมพักใจกระจก ไพ่กำลังใจ กระดานบ่น มุมกาแฟ โซฟารับฟัง ต้นไม้ โต๊ะเล่นเพลิน หน้าต่าง วงคุย และตู้จดหมาย ไม่มีแพ้ชนะ ไม่มีบทลงโทษ
  • พี่ฟ้า (AI)นั่งอยู่ที่โซฟา เป็นตัวละคร AI ที่รับฟัง ไม่ใช่นักจิตวิทยา ถ้ามีเรื่องหนักใจมาก โทรสายด่วนสุขภาพจิต 1323 ได้ตลอด 24 ชั่วโมง
  • สมุดของฉันเก็บไพ่ จดหมาย บันทึกต้นไม้ และผลงาน ไว้ในเครื่องนี้เท่านั้น
  • พลังงานลดลงเมื่อทำงาน เติมได้ที่มุมกาแฟ ตู้น้ำ โซฟา และหน้าต่าง
